# LOCKET — Backend

API and services for LOCKET.

## Getting started

```bash
# install dependencies, then
npm run dev
```

## Structure

```
backend/
├── src/          # application source
├── tests/        # test suite
└── README.md
```

## Environment

Copy `.env.example` to `.env` and fill in the values. Secrets, keys, and
credentials must never be committed — `.env*` files are ignored by git.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the server with reload |
| `npm start` | Start the server |
| `npm test` | Run tests |
